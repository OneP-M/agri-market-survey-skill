# 市场调查与分析大赛技能
一款可移植的Codex技能，用于完成**全国大学生市场调查与分析大赛**完整项目。
本技能不限制行业领域，可适用于以下选题方向：
- 农业与食品；
- 消费品；
- 服务业；
- 文旅；
- 能源与绿色消费；
- 教育；
- 医疗健康；
- 数字产品；
- 公共服务；
- 乡村发展；
- 其他市场调研领域。

## 预期工作流程
使用者先选定具体选题，之后该技能可辅助完成以下工作：
1. 选题确定与可行性评估；
2. 问卷可实施性评估；
3. 与近三届获奖作品的选题重复筛查；
4. 结合政策依据论证选题的社会意义；
5. 研究问题提炼；
6. 问卷与抽样方案设计；
7. 预调研与数据清洗；
8. 数据分析与受众细分；
9. 市场对策建议；
10. 竞赛报告与汇报材料制作。

本技能不会自动替换用户选定的选题，也不默认研究主题必须聚焦农业。
